# Sample Music Player

A sample iOS music player built with SwiftAudioEx.

## Description

Sample Music Player is a simple iOS app that searches and plays music using [SwiftAudioEx](https://github.com/DoubleSymmetry/SwiftAudioEx) as the audio engine. Music data and previews are fetched from the [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html).

## Getting Started

### Dependencies

* **Alamofire** – handles API requests
* **Kingfisher** – downloads and caches images from URLs
* **SwiftAudioEx** – audio engine for playing music previews from iTunes
* **Activity indicator** – shows a loading state while API requests are in progress
