# Sample Music Player

Sample music player with SwiftAudioEx

## Description

Sample music player with SwiftAudioEx and source music from Apple Music iTunes Search API

## Getting Started

### Dependencies

* I use an activity indicator when load api
* Alamofire for request api
* Kingfisher - get image from URL 
* SwiftAudioEx - Engine audio to play music from iTunes
